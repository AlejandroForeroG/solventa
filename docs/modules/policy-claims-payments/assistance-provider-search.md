# Assistance provider search

Policy serves a synthetic directory of workshops, experts and roadside assistance in Bogotá and Medellín. Provider names, addresses, phone placeholders and hours are synthetic. The catalog is bundled with the adapter, requires no migration, and performs no network I/O. The directory does not need a map SDK or API key.

Manual search matches a supported city, fixture address or fixture address plus city. Matching ignores case, accents and extra whitespace. Nearby search validates latitude and longitude and returns results within a 25 km straight-line radius, closest first. The radius is a provisional rule for the synthetic directory. A result includes the provider reference, category, display name, address, phone and hours. Nearby results also include the distance in kilometers.

The adapter rejects unknown catalog versions, malformed records and duplicate provider references as unavailable. An empty list means the catalog was valid and had no matching provider. This distinction lets a caller offer manual search or continue filing a claim after a directory failure. The [versioned catalog schema](../../../packages/contracts/schemas/synthetic-assistance-directory.v1.json) and positive and negative corpus run in `npm run test:integrations`.

Web and native use [POST /api/v1/assistance/providers/search](../../../packages/contracts/openapi/v1/assistance-providers.yaml). The gateway forwards the bounded JSON body to Policy after the version gate. Policy checks `assistance-providers:read` with Identity in one binding call. Web uses the sealed session and Origin check. Native uses the existing bearer session. Partners do not receive this operation. Successful responses are uncached and contain only the simulated matches and correlation identifier. Directory failure is a separate 503 from an empty result and cannot block the independent claim route.

For coordinate search, the client explains the purpose before requesting foreground location. The request requires explicit authorization for that search and valid coordinates. Manual search requires no location permission. No location or manually entered place is saved, logged or sent to a third party. The read-only lookup changes no claim or financial state. The assistance request feature owns provider selection, confirmation, persistence, idempotency and status tracking once its contract is available.

Run `npm run test:integrations` and `npm run test:pact` for authenticated web/native routing, the versioned catalog, consent input, normalized failure and empty results. Use the [web](../../channels/web/README.md#assistance-provider-search) and [mobile](../../channels/mobile/README.md#assistance-provider-search) guides for interactive checks.
