# Desarrollo

- Mantener independientes los tres backends y sus datos. El dominio y la aplicación no importan SDK de infraestructura.
- Compartir contratos de frontera; no compartir entidades ni repositorios de dominio.
- No guardar secretos ni datos personales reales. Usar fixtures sintéticos.
- Mantener el texto de interfaz mínimo y funcional.
- Documentar comandos, interfaces y decisiones técnicas implementadas. No guardar planificación, informes internos ni contexto de conversaciones.
- Verificar el cambio con los comandos pertinentes. No presentar scaffolding o mocks como funcionalidades completas.
